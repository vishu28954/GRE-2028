# GRE Vocabulary — Group 2

This folder contains the vocabulary studied in Group 2.

## Daily study format

Each word should include:
- Pronunciation
- English meaning
- Hindi meaning
- Visual association
- Memory hook
- Synonyms
- Antonyms
- 2–3 contextual example sentences or a short paragraph
- GRE usage notes / distinctions

## Daily target

15 new GRE words per day.
