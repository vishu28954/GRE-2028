# GRE 2028 — Master Study Structure

This repository is the structured study notebook for GRE preparation.

The goal is not to collect disconnected notes. The goal is to build a system in which vocabulary, verbal reasoning, revision, testing, and long-term retention reinforce one another.

---

# Core Learning Philosophy

GRE preparation should move through the following progression:

```text
LEARN
  ↓
RECOGNIZE
  ↓
RECALL
  ↓
DISTINGUISH
  ↓
APPLY IN GRE QUESTIONS
  ↓
REVISE
  ↓
MASTER
```

A topic is not considered mastered merely because its definition or rule looks familiar.

The final goal is to use that knowledge accurately under GRE-style conditions.

---

# 1. Vocabulary Curriculum

## Daily Vocabulary Target

Study exactly **15 new GRE words per vocabulary day**.

Words should not be taught as isolated dictionary definitions. Each day should be organized around a meaningful **semantic theme or word family**.

Examples:

```text
Day 1 → Personality, Speech & Behavior
Day 2 → Praise, Criticism & Contempt
Day 3 → Intelligence, Ignorance & Judgment
...
```

The purpose of thematic grouping is to create a mental network between related words.

---

# 2. Standard Vocabulary Lesson Format

Every vocabulary word should follow the same learning structure.

## Required Sections

```text
1. Word + Part of Speech
2. Pronunciation
3. English Meaning
4. Hindi Meaning
5. Visual Association with an actual relevant image
6. Visual Scene / Mini Story / Dialogue
7. Memory Hook
8. Synonyms
9. Antonyms
10. Usage Paragraph
11. GRE Connections / Distinctions
```

## Visual Learning Standard

Every word must contain a **real visible image** in the Visual Association section.

Preferred sources include stable and reusable sources such as:

- Wikimedia Commons
- official/public institutional galleries
- other reliable public visual sources

The image should encode the meaning of the word rather than merely decorate the page.

Example:

```text
LAUD
→ award ceremony
→ public recognition
→ applause
→ strong public praise
```

The visual section should then include a short scene or dialogue that makes the meaning intuitive.

---

# 3. Semantic Network Learning

Vocabulary should always be learned through relationships.

For each group, identify:

- near-synonyms
- antonyms
- differences in tone
- differences in intensity
- differences in context
- formal vs informal usage
- Sentence Equivalence partners
- common GRE traps

Example:

```text
ADMONISH
→ warning + correction

REBUKE
→ sharp direct disapproval

CENSURE
→ formal/institutional disapproval

CASTIGATE
→ extremely harsh criticism
```

These words should never simply be memorized as four versions of “criticize.”

---

# 4. End-of-Day Vocabulary Structure

Every vocabulary lesson should finish with the following sections.

## Cluster Summary

Words grouped by semantic function.

## Visual Contrast Map

A compact visual reminder connecting each word with its main scene.

## Important GRE Traps

Near-synonyms that are easy to confuse.

## Quick Revision Table

Suggested columns:

```text
Word | Core Meaning | Visual Memory | GRE Pair / Contrast
```

## Final Memory Network

A tree or map showing how all 15 words relate.

## Testing Progression

```text
Stage 1
Visual + Meaning Recall

        ↓

Stage 2
Synonym / Antonym Relationships

        ↓

Stage 3
GRE Sentence Equivalence + Text Completion
```

# 5. Vocabulary Mastery System

Every word progresses through the following stages:

```text
NEW
 ↓
RECOGNIZE
 ↓
RECALL
 ↓
DISTINGUISH
 ↓
USE IN GRE QUESTION
 ↓
MASTERED
```

## Recognition

You understand the word when you see it.

## Recall

You can produce the meaning without being shown it.

## Distinguish

You can differentiate it from closely related words.

Example:

```text
laconic vs taciturn vs reticent

laud vs extol vs acclaim

admonish vs rebuke vs castigate
```

## GRE Application

You can correctly use the word in Text Completion or Sentence Equivalence.

Only after this stage should a word be considered truly mastered.

---

# 6. Spaced Revision System

Vocabulary should be repeatedly retrieved rather than simply reread.

## Revision Cycle

```text
Same Day
→ immediate recall after learning

Next Day
→ short retrieval before new vocabulary

Day 3
→ mixed cumulative quiz

Day 7
→ larger cumulative review

Later Reviews
→ mixed GRE-style questions containing old + new vocabulary
```

Previously studied words should also appear naturally inside later explanations and example sentences.

This creates continuous reinforcement instead of isolated vocabulary sessions.

---

# 7. GRE Verbal Application Track

Vocabulary development and GRE question-solving should run **in parallel**.

Do not wait until hundreds of words have been memorized before practicing Verbal questions.

The planned progression is:

```text
Vocabulary Foundation
        ↓
Text Completion
        ↓
Sentence Equivalence
        ↓
Reading Comprehension
        ↓
Mixed GRE Verbal Sets
```

---

# 8. Text Completion Curriculum

Text Completion should be introduced early because it teaches sentence logic.

Core skills:

- identifying sentence direction
- detecting contrast and continuation words
- predicting the blank before looking at options
- identifying tone
- recognizing positive/negative shifts
- understanding cause and effect
- matching vocabulary precisely to context

Vocabulary learned in previous groups should be reused in these exercises.

---

# 9. Sentence Equivalence Curriculum

Sentence Equivalence practice should focus on both **meaning** and **equivalent sentence outcome**.

Core skills:

- identifying the sentence's logical requirement
- finding true synonym pairs
- rejecting choices that are individually plausible but not equivalent
- recognizing GRE synonym families
- distinguishing near-synonyms with different tone or intensity

Examples of useful vocabulary relationships:

```text
LAUD ≈ EXTOL

DISPARAGE ≈ DENIGRATE

DERIDE ≈ RIDICULE

SCORN ≈ DISDAIN
```

---

# 10. Reading Comprehension Curriculum

Reading Comprehension should begin after the basic Text Completion and Sentence Equivalence logic is established.

Focus areas:

- passage structure
- author's main point
- author's tone
- purpose of a paragraph or sentence
- inference
- strengthen/weaken logic
- evidence vs opinion
- resolving apparent contradictions
- eliminating attractive but unsupported answers

RC preparation should prioritize reasoning rather than speed at the beginning.

---

# 11. Mixed GRE Verbal Practice

Every few vocabulary groups, complete a mixed set containing:

- previously learned vocabulary
- Text Completion
- Sentence Equivalence
- Reading Comprehension
- deliberately confusing near-synonyms

Questions should increasingly mix old and new material so that earlier vocabulary remains active.

---

# 12. Recommended Study Sequence

The immediate learning sequence should be:

```text
1. Learn the next 15-word vocabulary group

2. Complete Day 1–2 cumulative vocabulary revision

3. Begin Text Completion strategy

4. Solve GRE-style Text Completion questions

5. Continue new vocabulary groups

6. Introduce Sentence Equivalence

7. Run 3-day and 7-day vocabulary reviews

8. Begin Reading Comprehension

9. Progress toward mixed GRE Verbal sets
```

This prevents vocabulary study from becoming disconnected from actual GRE performance.

---

# 13. Repository Workflow

The repository should contain only **polished final study material**.

The working process is:

```text
Draft lesson in ChatGPT
        ↓
Review and refine
        ↓
Approve final version
        ↓
Push approved version to GitHub
```

GitHub is the final study notebook, not the drafting area.

---

# 14. Standard for Future Lessons

Every future lesson should aim to be:

- detailed but organized
- visually memorable
- conceptually connected
- GRE-specific
- cumulative
- testable
- revision-friendly

The purpose is not passive familiarity.

The purpose is **usable GRE Verbal mastery**.
